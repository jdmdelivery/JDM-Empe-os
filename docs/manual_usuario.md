# Manual de usuario — JDM Empeños (Fase 1)

## Inicio de sesión

1. Abra la URL del sistema.
2. Ingrese usuario o correo y contraseña.
3. Si es el primer acceso, cambie la contraseña.

## Panel

Muestra indicadores base y actividad reciente. Los KPIs de empeños/ventas/caja se activarán en fases posteriores.

## Sucursales

Disponible para Superadministrador: crear, editar, activar y desactivar sucursales.

## Usuarios

Administradores y Superadministradores pueden crear empleados, asignar roles y sucursal.

## Configuración

Nombre del negocio, RNC, contactos, símbolo `RD$`, zona horaria e interés predeterminado.

## Auditoría

Consulta de acciones del sistema e intentos de acceso.

## Roles

| Rol | Uso |
|-----|-----|
| Superadministrador | Todo el sistema |
| Administrador | Su sucursal |
| Cajero / Empleado | Operaciones diarias |
| Auditor | Solo lectura |
